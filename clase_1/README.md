# Clase 1

Ejemplos de chat y agente:

- `agente_basico.py`: agente con herramienta de fecha.
- `chat_llm.py`: chat directo con OpenRouter.
- `chat_langchamp.py` y `guiado_clase.py`: ejemplos con LangChain.
- `movie.py`: respuesta estructurada con datos de películas.

Desde `a1-chat-llm`, puedes ejecutar los chats así:

```powershell
.venv\Scripts\python.exe -m clase_1.agente_basico
.venv\Scripts\python.exe -m clase_1.chat_llm
.venv\Scripts\python.exe -m clase_1.chat_langchamp
.venv\Scripts\python.exe -m clase_1.guiado_clase
```

La configuración `.env`, el entorno `.venv` y `requirements.txt` se comparten
desde la carpeta `a1-chat-llm`.
